# Carom

Carom is a top-down paddle duel built around spin and bank shots. Rally across a dark, neon-lit field, bend shots with paddle motion, and use the two central obstacles to outmaneuver your opponent.

## Install

```sh
npm ci
```

## Run in development

```sh
npm run dev
```

Open the local URL Vite prints in the terminal.

## Production build

```sh
npm run build
```

Vite writes the complete static site to `dist/`. Serve that directory from the root of any static web server.

## Controls

- **Solo:** W/S moves your paddle; the AI controls the other side.
- **Versus:** W/S controls player one and the arrow keys control player two.
- **Menus:** Up/down (W/S or arrows), Enter/Space to select, Escape to go back or pause, P to pause.
- **M** toggles sound. Touch controls are also available on touchscreens.
